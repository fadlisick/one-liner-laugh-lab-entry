A make.fun entry for the One-Liner Laugh Lab bounty. The program writes a
single funny line to entry.txt: the excuse a robot vacuum gives after
eating a sock. The line is short, deadpan, and fits the prompt exactly.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/laughlab-out python3 main.py
cat /tmp/laughlab-out/entry.txt
```

The entrypoint is main.py, packed from the readable source sock.py with
the kit's compress step. It writes one line of at most 200 characters to
entry.txt under the output folder the harness points at.
